# Noto fallback fonts

Noto Sans JP and Noto Sans KR, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset

The supplied fonts were instantiated at weight 400 from NotoSansJP-VF.ttf and
NotoSansKR-VF.ttf using fontTools.varLib.instancer. They retain their embedded
copyright and licensing metadata. They are loaded from RomFS only when Japanese
or Korean is selected, rather than embedded in the shared plugin memory region.
